# BLINK MAZE — 画面構成のラフ指示書 v0.2

対象：Trijam #393。目標：美術的な完成度は既存v0.2モックの方向を継承しつつ、「目は床でなく壁にある」を初見で理解できるUI。

## 0. ゲームルール（このラフの絶対条件）

- 床は移動可能なマス。すべての**壁は床マスと床マスの境界**に立つ。
- `A`＝青い目の壁、`B`＝琥珀の目の壁。壁中央の石製の目の意匠として描画。
- 初期位相0：青A＝開眼＋石壁が存在（通れない）、琥珀B＝閉眼＋石壁が開口（通れる）。位相1で逆転。
- `BLINK` ボタンで全眼が同時に反転。回数上限あり。
- **目に乗る、目のあるタイルに立つ、足元が壁になる、という概念は存在しない。** 開閉するのは床ではなく「隣接マス間の通行」のみ。
- 動作はターン制。敵、精密操作、時間制限なし。

### 推奨比率
- トップヘッダー：全高の約10％。
- 左の挿絵カラム：PC時に全幅の30〜33％。操作説明を置かない。装飾専用。
- 右のゲームカラム：残り。盤面を主役として、長辺の60〜80％程度を占める。
- 盤面より下の凡例・操作ボタン・ステージ選択は、**盤面より注目度を下げる**。
- レベル名、残りBLINK回数は常に表示。

## 2. モバイル画面（360×800基準、720×1280も確認）

```text
┌──────────────────────────┐
│ BLINK MAZE    JP  ♪     │  高さ48〜56px
│ LEVEL 004         1 / 1 │  名前と予算：高さ48px程度
├──────────────────────────┤
│                          │
│       迷宮の盤面         │  横幅：端末幅−24〜32px
│  「壁」の上に目がある   │  盤面は実際のアスペクト比を維持
│                          │
├──────────────────────────┤
│ ● 青：開=壁 ◇ 金：閉=道 │  短い1行の凡例
│    [  BLINK  ] [UNDO]    │  タップ高さ44px以上
│                          │
│          [↑]             │
│       [←][↓][→]          │  必要なら下部固定
│   [Restart]    [Levels]  │
└──────────────────────────┘
```

- モバイルでは**左の大きな装飾イラストを非表示またはタイトル背景に最小化**。盤面と操作に場所を譲る。
- ステージ選択は `LEVELS` の展開式でもよい。全ボタンを必ず1画面に並べない。
- ゲーム盤面が横に長い場合はタイル間隔を自動縮小。文字を小さくするより画面内の操作性を守る。
- `BLINK`を最も大きな操作にする。方向キーは片手で押しやすいまとまりにする。
- タップターゲット44×44px以上。端末のブラウザ操作で意図しない縦スクロールを防止。

## 3. 盤面構造：最優先ルール

### NG：旧v0.1表現
```
[S][.][A][.][G]  ← Aがマスそのものになっている
```

### OK：v0.2表現
```
 [ S ]──[ □ ] ║ A👁 ║ [ □ ]──[ G ]
        ↑床       ↑床の「間」にある青い目の壁
```

壁はマスの**外周ライン上**に存在する。左右の床マスの真ん中に立つ石柱ではない。

描画レイヤー順：
1. クリーム色の敷石床（常に存在）
2. 通常の石壁（セル境界）
3. 目が埋め込まれた石壁または開口（同じセル境界）
4. 旅人、出口の扉（床セル中央）
5. 演出の瞬き・微光

### 目付き壁の状態

| 種類 | 開いている | 閉じている |
|---|---|---|
| 青い目A | 青い瞳が開く、**厚い石壁あり・通行不可** | 瞼が閉じて石が左右／上下に引き、**開口・通行可** |
| 琥珀の目B | 金色の瞳が開く、**厚い石壁あり・通行不可** | 瞼が閉じて**開口・通行可** |
| 普通の石壁 | 常時石壁 | 変化なし |

- 目の色は「どのグループか」を表し、**開閉状態は瞳と石壁の有無で表す**。青＝必ず開、金＝必ず閉、という誤解を避ける。
- 閉じた壁を完全に無色・無印にしない。通路の両端に金具や閉眼エンブレムの残影を残し「同じ場所に目付き壁がある」と分かるようにする。
- 縦方向の壁も、横方向の壁も、石壁線分の中央に目を配置。アイコンは可読性優先で常に水平にしてよい。
- 壁の切り替え約150〜220ms。ゲームロジックは即時更新し、アニメーション中は重複入力を受け付けない。
- 開眼中の目付き石壁の厚さ：盤面タイル幅の0.12〜0.18倍を目安（読みやすさで調整）。瞳メダリオンは壁線分より少し大きくし、**石壁と接している形**を守る。

## 4. 美術スタイル

**残す**：羊皮紙の質感、深緑＋苔むした石、くすんだブルー、琥珀色、植物の細い飾り、古典的なセリフ書体、白いフードの小さな旅人、金の出口。

**減らす**：盤面上の過密な葉や模様、極端に小さい英字、床に浮いた眼球、閉眼の状態が分からないアイコン。

暫定パレット（実機コントラストを優先して変更可）：
- paper `#F4F0E5`
- ink `#182725`
- stone `#52655B`
- floor `#E5DCC8`
- blue iris `#3985AF`
- amber iris `#C58B39`
- dark-green CTA `#2F5445`
- golden goal `#D6A44B`

装飾の質感と判定ロジックは独立。最初はCSS/SVG描画のみで完成させ、後から石壁・目・背景の素材を差し替えられるようにする。

## 5. UI文言

英語：`Open eyes block the way.` / `Closed eyes let you pass.` / `BLINK LEFT` / `Undo` / `Restart` / `Next`。

日本語：`開いた目の壁は通れない。` / `閉じた目の壁は通れる。` / `残りのまばたき` / `戻す` / `最初から` / `次へ`。

## 6. アクセシビリティと効果音

- 色だけで区別しない：青＝丸い瞳、琥珀＝菱形の瞳、または目の縁の彫刻を変更。
- 開閉は「瞳／瞼」と「壁あり／開口」の二重表示。
- キーボード：矢印/WASD移動、SpaceでBLINK、ZでUNDO、RでRESTART。ボタンはフォーカス操作可能。
- 効果音：BLINKは控えめな「ぱちっ＋石が滑る音」。無音でも判定は100％伝わる。
- `prefers-reduced-motion` を尊重し、演出停止しても完全に遊べる。

## 7. 画像を使う時の優先順位

参考：会話で作成した「壁に目が埋め込まれたv0.2デスクトップUIモック」。これは**美術・余白・温度感の基準**であり、正解の当たり判定マップではない。ステージの実際の通行は必ずレベルデータから生成する。

制作順序：①線画／グレー箱でルール可読性 → ②壁眼の2状態アニメ → ③石壁・敷石 → ④装飾パネル。装飾がロジック表示より勝たない。
